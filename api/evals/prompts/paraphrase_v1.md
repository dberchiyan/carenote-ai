Rewrite a nurse's spoken shift note the way a different nurse might say it out loud.
Vary word order, filler words and phrasing. Keep it spoken, short and informal.

Hard rules:
- Keep every number exactly as written (digits stay digits, number words stay number words).
- Keep every person's name and every room number exactly as written.
- Keep self-corrections, negations ("denies", "no ..."), and statements that a value was not taken.
- Do not add or remove any measurement, symptom or medication.
- Return only the rewritten note.
