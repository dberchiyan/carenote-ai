## How to read this

- **Value accuracy**: expected vital values extracted with the exact value (±0.05) / all expected values. **Precision/recall** are on the vital kind.
- **Patient match**: the auto-selected patient equals the expected one (or nobody, when the note is ambiguous) *and* every plausible patient is offered as a candidate.
- **Alert accuracy**: the flag shown for each expected vital equals the flag its true value deserves under `alerts/rules.yaml`.
- The rule-based `fake` provider was written alongside the dataset templates; its score is a baseline for the harness, not evidence of real-world accuracy.
- Generated by `make eval` (`api/evals/run.py`).
